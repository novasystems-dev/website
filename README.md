## ⚡ Overview

This repository hosts the official web portal for the **Nova Systems Programming Language**, accessible at:
👉 **[https://novasystems-dev.github.io](https://novasystems-dev.github.io)**

The website features:
- **Interactive Multi-OS Quick Installer**: One-line copy commands for Linux, macOS, Windows PowerShell, and Docker.
- **Interactive Code Showcase**: Tabbed live examples demonstrating Perceus zero-GC recycling, Z3 SMT formal verification, bare-metal hardware raw pointers, and capability-gated concurrency.
- **Language Benchmarks**: Latency, GC pauses (0.0ms), and memory footprint compared to Rust, C++, Go, and Zig.
- **Ecosystem Navigator**: Direct links to all satellite repositories in the `@novasystems-dev` universe.

## 🚀 Running Locally

To preview the website locally without any dependencies:

```bash
# Python 3 built-in HTTP server
python3 -m http.server 8080

# Or with Node.js
npx serve .
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
