Architecture

Engineered for Correctness & Speed

Nova unifies the ergonomic safety of Rust, the raw execution speed of C, and the mathematical rigor of formal verification.

⚡

Perceus In-Place Reuse

Zero garbage collection. When an object's reference count is 1, mutations execute destructively in place without allocating new memory chunks, eliminating runtime latency spikes.

📐

SMT Refinement Types

Compile-time formal verification via Microsoft Z3. Array bounds, non-zero division, and buffer invariants are mathematically proven before your program ever runs.

🛡️

Capability Concurrency

Memory isolation is enforced by the type system through iso, val, and ref capabilities, eliminating data races at compile time.

⚙️

Bare-Metal Parity

First-class raw pointers (*mut T, *const T), inline assembly, and direct FFI integration for writing kernels, hypervisors, and high-frequency trading engines.
